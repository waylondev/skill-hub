# COBOL 现代化技能（cobol-modernization）

## 概述

本技能用于将 COBOL 程序、Copybook、批处理作业、在线事务等遗留资产迁移至现代 Java 技术栈。技能覆盖从源码解析、架构设计、代码生成到生产部署的完整生命周期，并针对大体量生产项目提供了增量分析、并行处理、断点续传等企业级能力。同时，从用户使用角度出发，提供了交互式配置向导、详细的日志与监控、故障排除指南、报告可视化以及最佳实践，帮助团队快速上手并高效完成迁移。

## 适用场景

- 大型主机 COBOL 应用的全面迁移
- 增量式现代化（逐步替换模块）
- 多方言 COBOL 源码的统一分析
- 需要严格回归测试和安全合规的金融、保险等领域
- 团队协作、多阶段交付的复杂迁移项目

## 前置条件

- 提供 COBOL 源码的编码格式（EBCDIC/ASCII）及记录长度
- 明确目标方言（IBM Enterprise COBOL、Micro Focus、GnuCOBOL 等）
- 准备可执行的测试用例或输入/输出对（用于回归验证）
- 安装必要的预处理工具（如 `iconv`、`cobol-formatter`，详见工具链实用程序阶段）

## 技能版本

当前版本：2.1.0（详见 CHANGELOG.md）

## 快速入门

1. **环境准备**：确保已安装 Java 17+、Maven/Gradle、Docker（可选）及本技能所需的辅助工具。
2. **配置方言**：运行交互式配置向导，选择目标 COBOL 方言并指定源码路径。
   ```bash
   agent run cobol-modernization --wizard
   ```
3. **预处理源码**：根据向导提示，对源码进行编码转换和格式标准化。
4. **执行分析**：启动增量分析，生成调用图和依赖矩阵。
5. **审查结果**：查看生成的 HTML 报告，确认依赖关系和潜在风险。
6. **开始迁移**：按阶段顺序执行迁移，每个阶段输出中间产物。
7. **验证正确性**：在关键阶段后运行自动化回归测试。
8. **部署上线**：通过 CI/CD 流水线将迁移后的服务部署至目标环境。

## 交互式配置向导

技能提供命令行交互式向导，引导用户完成初始配置：

- 选择 COBOL 方言（IBM Enterprise COBOL / Micro Focus / GnuCOBOL / 自定义）
- 指定源码根目录及文件扩展名
- 设置输入编码（EBCDIC / ASCII）及记录长度
- 配置输出目录、Java 包名、Spring Boot 版本等
- 选择启用的增强功能（增量分析、并行处理、安全扫描等）
- 生成配置文件 `cobol-modernization.yaml`，供后续阶段使用
